5. CRITICAL ARCHITECTURE CODE SNIPPETS

A. PDF Service External Execution Loop

Due to heavy Vercel limits, the architecture ships the HTML template to an external service. This is critical for scaling.

export class PDFService {
  static async convertHtmlToPdfBuffer(htmlContent: string): Promise<Buffer> {
    const customJsApiKey = process.env.CUSTOMJS_API_KEY;
    const customJsBaseUrl = process.env.CUSTOMJS_BASEURL || 'https://api.customjs.space';
    
    // Calls the heavy puppeteer lifting API externally
    const response = await fetch(`${customJsBaseUrl}/pdf/generate`, {
      method: 'POST',
      headers: { 'Content-Type': 'application/json', 'x-api-key': customJsApiKey },
      body: JSON.stringify({ html: htmlContent })
    });
    
    return Buffer.from(await response.arrayBuffer());
  }
}

B. The Auth Middleware Edge Defense

This snippet guarantees pure isolation and forces unauthenticated users away from dangerous zones.

export default withAuth(
  function middleware(req) {
    const token = req.nextauth.token;
    const path = req.nextUrl.pathname;

    // Total blockade for non system_admins attempting DB changes
    if (path.startsWith("/admin")) {
      if (token?.role !== "system_admin") {
        return NextResponse.redirect(new URL("/agency/dashboard", req.url));
      }
    }
    return NextResponse.next();
  }

6. EXHAUSTIVE BUG ANALYSIS & ARCHITECTURAL RED FLAGS

1. OneDrive/Desktop File Duplication & Build Crashes
Problem: Scattered across src/models and src/services are files appending -DESKTOP-HQJKU6N.ts. This is a fatal sync conflict. Next.js compiler maps multiple identical exported schemas, crashing the local npm run dev.
Fix: Developers MUST wipe these files entirely and restrict code movement to git only.
2. Form Template Dynamic Typing Disconnect (No Zod)
Problem: When DynamicForm.tsx pushes the payload: {} block to /api/submissions, the API blindly accepts the JSON blob into MongoDB. There is NO server-side verification that the submitted payload matches the FormTemplate constraints.
Fix: Implement Zod dynamically: const schema = z.object(buildZodShape(template.fields)); in the POST endpoint BEFORE saving to DB.
3. Status Mismatch Desynchronization
Problem: PaymentService.ts forces Quotes to PAID. If the parent Submission document isn't correctly updated in the same tick, an Agency sees "Payment required" while Admin sees "Paid".
Fix: Enforce Mongoose Transactions (session.startTransaction()) wrapping operations that touch both Quote and Submission status simultaneously.
4. Mongoose Type Casting Anomalies
Problem: Heavy use of const data = doc.foreignId as any because TypeScript natively treats ObjectIds as non-populated strings, rejecting data.name requests.
Fix: Enforce IPopulatedQuote Generics natively at the model definition layer to remove all as any loopholes.

7. PERFORMANCE OPTIMIZATION BLUEPRINT

API & DB Speed Fixes

  • Reduce Payload Fetches: Currently /admin/submissions/page.tsx fetches immense JSON payloads just to render table rows. Add .select('-payload -clientContact') to the initial Mongoose GET array.
  • Index Missing: SubmissionSchema.index({ agencyId: 1, status: 1 }) MUST be added. As table rows hit 10k+, the dashboard will lock up without this composite index.
  • Image Bloat in PDF: Shift rendering from inline base64 image injections to HTTPS external URL links. Decreases API latency for PDFs from 12s → 3s.

8. MAXIMUM SECURITY INFRASTRUCTURE

Protection Measures

  • Strict Backend Token Matching: In every API route, ensuring Submission.findOne({ _id: id, agencyId: token.agencyId }) guarantees Tenant Isolation. Brokers can NEVER spoof query parameters.
  • Rate Limiting Needed: Install @upstash/ratelimit and wrap the /api/auth/[...nextauth] and /api/submissions endpoints. Limit to 5 req/minute. Defends against credential stuffing.
  • JWT Integrity: Rely on secure Edge runtime strategy. Never store raw UUIDs in localStorage.
